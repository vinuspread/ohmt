## 전체 방향

**Before**

> 검증된 디자인으로 브랜드를 완성

**After**

> 검증된 디자인으로 시작해,  
> 우리 브랜드만의 사이트로 완성합니다.

현재 문구는 짧지만 OHMT가 브랜드 전체를 완성하는 것처럼 범위가 크게 들립니다. 개선안은 실제 제공 결과인 “브랜드 사이트”를 분명하게 말합니다.

## 3. 고객이 겪는 문제

### 제목

**Before**

> 웹사이트 제작을 시작할 때 대부분 여기서 막힙니다.

**After**

> 사이트 하나를 열기까지, 결정할 일이 너무 많습니다.

### 설명

**Before**

> 직접 만들면 오래 걸리고, 외주는 부담스럽습니다.  
> OHMT는 바로 시작할 수 있는 제작 방법을 제공합니다.

**After**

> 기획, 디자인, 문구, 이미지, 기능을 처음부터 모두 정하면 시간과 비용이 커집니다. OHMT는 검증된 디자인과 전담 제작팀으로 이 과정을 줄입니다.

### 문제 카드

| Before | After |
|---|---|
| 무엇을 어떻게 담아야 할지, 막막합니다 | 무엇을 담아야 할지 정리하기 어렵습니다 |
| 화면 구성부터 콘텐츠까지 혼자 정해야 합니다. | 필요한 페이지와 콘텐츠의 순서를 잡기 어렵습니다. |
| 시작하기도 전에 부담스러운 비용 | 맞춤 외주의 비용과 일정이 부담됩니다 |
| 견적부터 계약까지, 진입장벽이 높습니다. | 처음부터 새로 만들면 비용과 제작 기간이 커집니다. |
| 오픈 후엔 누구에게 맡기나요 | 오픈 뒤 작은 수정도 맡길 곳이 필요합니다 |
| 수정 하나에도 다시 개발자를 찾아야 합니다. | 문구나 이미지 하나를 바꿀 때도 새로운 업체를 찾아야 합니다. |

### 해결 방식

| Before | After |
|---|---|
| 필요한 내용과 콘텐츠 구성을 함께 정리합니다. | 필요한 페이지와 콘텐츠를 먼저 정리합니다. |
| 신속한 결정이 가능해 비용과 기간을 줄입니다. | 완성된 디자인에서 시작해 결정과 제작에 드는 시간을 줄입니다. |
| 오픈 후 수정과 관리를 전담 팀이 지원합니다. | 만든 팀이 오픈 이후의 수정과 운영을 이어서 지원합니다. |

## 4. OHMT 제작 방식

### 제목

**Before**

> 우리는 템플릿을 팔지 않습니다.  
> 브랜드에 맞게 커스텀합니다.

**After**

> 템플릿에서 시작하지만,  
> 그대로 만들지는 않습니다.

`템플릿을 팔지 않는다`는 문장은 실제 서비스 방식과 충돌하고 방어적으로 들립니다. 개선안은 템플릿 기반이라는 사실을 인정하면서 차별점을 설명합니다.

### 설명

**Before**

> 컨셉에 맞는 템플릿을 선택하면 브랜드에 최적화된 웹사이트를 제작합니다.

**After**

> 선택한 디자인에 브랜드의 문구, 이미지, 색, 글꼴, 페이지와 필요한 기능을 적용해 실제 운영할 사이트로 완성합니다.

### 3단계

| 단계 | Before | After |
|---|---|---|
| 1 | 방향성 선택 | 맞는 디자인 찾기 |
| 설명 | 업종과 브랜드 톤에 맞는 템플릿 방향을 고릅니다. | 업종, 목적, 원하는 인상을 기준으로 시작점을 고릅니다. |
| 2 | 전문가 제작 | 브랜드에 맞춰 제작하기 |
| 설명 | 카피, 이미지, 구조를 브랜드에 맞게 조정합니다. | 문구와 이미지, 페이지 구성, 필요한 기능을 실제 사업에 맞게 적용합니다. |
| 3 | 오픈과 운영 | 점검하고 오픈하기 |
| 설명 | 배포 후 수정과 업데이트를 이어갑니다. | 모바일 화면과 링크, 검색 정보, 문의 흐름을 확인한 뒤 오픈합니다. |

## 6. 디자인 목록

### 제목

**Before**

> 현재 등록된 템플릿

**After**

> 우리 브랜드의 시작점이 될 디자인

### 설명

**Before**

> 템플릿을 선택하고 브랜드에 맞게 제작을 상담해 보세요.

**After**

> 화면의 분위기와 함께 필요한 페이지와 기능을 살펴보세요. 선택한 디자인은 브랜드에 맞게 다시 조정합니다.

### 검색 안내

**Before**

> 템플릿 이름, 설명, 카테고리 검색

**After**

> 업종이나 원하는 분위기로 찾아보세요.

### 버튼

| Before | After |
|---|---|
| 템플릿보기 | 미리 보기 |
| 이 템플릿 상담하기 | 이 디자인으로 상담 |
| 더보기 | 설명 보기 |
| 템플릿 더보기 | 디자인 더 보기 |

### 카드 설명 방식

**Before**

> 긴 문단으로 디자인, 섹션, 추천 업종을 한 번에 설명

**After**

> 추천 업종: 건축·인테리어·공간 디자인  
> 핵심 구성: 프로젝트·서비스·팀 소개  
> 분위기: 절제된 미니멀

템플릿마다 설명 구조를 동일하게 맞추면 빠르게 비교할 수 있습니다.

## 7. 가격

### 제목

**Before**

> 필요한 제작 범위에 맞춰 선택하세요.

**After**

> 필요한 페이지와 맞춤 범위에 따라 선택하세요.

### 설명

**Before**

> Starter 패키지로 200만원에 빠르게 제작 가능합니다. 원하시는 페이지 수, 기능과 범위에 따라 최종 견적은 달라질 수 있습니다.

**After**

> 가격과 기본 제공 범위를 먼저 공개합니다. 상담에서 추가할 항목과 제외할 항목을 정한 뒤 최종 견적을 안내합니다.

### 패키지 설명

| 패키지 | Before | After |
|---|---|---|
| Starter | 빠르게 시작하기 위한 핵심 기능 패키지 | 빠르게 오픈할 기본 사이트가 필요한 경우 |
| Professional | 브랜드 맞춤형 프리미엄 디자인 패키지 | 페이지 구성과 디자인을 브랜드에 더 깊게 맞춰야 하는 경우 |
| Premium | 고객 맞춤화 기능확장 프리미엄 패키지 | 별도 기능과 서비스 구조 설계가 필요한 경우 |

### 가격 표기

| Before | After |
|---|---|
| 2,000,000원 | 200만원 |
| 평균 소요 기간: 2주 소요 / 부가세별도 | 평균 제작 기간 2주 · VAT 별도 |
| 협의필요 | 별도 협의 |

### 가격 하단 안내

**Before**

> 페이지 수, 수정 범위, 기능 추가, 운영 지원 범위에 따라 최종 견적이 달라집니다. 상담을 신청하면 담당자가 전화 또는 이메일로 필요한 범위를 확인한 뒤 정확한 견적을 안내해 드립니다.

**After**

> 최종 견적은 페이지 수, 디자인 변경 범위, 기능 추가, 운영 지원 여부에 따라 달라집니다. 상담 후 작업 범위와 일정이 담긴 견적을 안내합니다.
